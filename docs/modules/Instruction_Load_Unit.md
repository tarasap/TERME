# Instruction Load Unit

## Overview

The `Instruction_Load_Unit` is a module designed to handle the fetching phase in a processor pipeline. It acts as an interface between the Program Counter (PC) and the Instruction Memory. The module manages memory requests, monitors valid data signals, issues stalls when necessary, and buffers the fetched instructions for smooth pipeline execution.

## Parameters

| Parameter | Default Value | Description |
| :--- | :--- | :--- |
| `size` | 32 | The bit width for addresses and instructions. |

## Ports

| Port Name | Direction | Width | Description |
| :--- | :--- | :--- | :--- |
| `clk` | Input | 1 | Clock signal |
| `rst` | Input | 1 | Reset signal |
| `StallF_i` | Input | 1 | Pipeline stall signal (fetch stage) |
| `Imem_Valid_i` | Input | 1 | Valid signal indicating data from Instruction Memory is ready |
| `PC_i` | Input | `[size-1:0]` | Program Counter input |
| `Imem_Data_i` | Input | `[size-1:0]` | Raw instruction data fetched from Instruction Memory |
| `Imem_Req_ilu_o` | Output | 1 | Request signal sent to Instruction Memory |
| `Imem_Stall_ilu_o` | Output | 1 | Stall signal generated by the Instruction Load Unit |
| `PC_Enable_ilu_o` | Output | 1 | Enable signal to update the Program Counter |
| `Imem_Addr_ilu_o` | Output | `[size-1:0]` | Address output sent to Instruction Memory |
| `Instruction_ilu_o` | Output | `[size-1:0]` | Final instruction output to the pipeline |
